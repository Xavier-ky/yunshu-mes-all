# 云枢小智 Agent 基础能力边界

> 版本：1.0（2026-07-16）
> 适用角色：所有 MES 已授权角色
> 范围：Agent 运行时基础设施，不替代 MES 业务服务、数据库事务或权限校验。

## 1. 四类信息必须分层

| 层级 | 当前实现 | 用途 | 不能做什么 |
|---|---|---|---|
| 实时业务事实 | Spring Boot MES API / MySQL | 查询订单、工单、库存、质量、任务和状态 | 不能被 RAG 或聊天历史替代 |
| 业务知识 | Qdrant `mes_knowledge_v1` | 检索 SOP、生命周期规则、Agent 职责和数据合同 | 不能宣称当前库存、工单状态或实时产能 |
| 短期记忆 | `agent_runtime_state` | 保存用户会话中的当前任务、已确认事实与追踪号 | 默认不自动注入模型提示词，8 小时后过期 |
| 长期记忆 | `agent_runtime_state` | 保存用户明确确认的偏好、决策模式或运行备注 | 不自动学习、不自动影响排产和质量结论 |

因此，Qdrant RAG 是“项目知识库”，不是“用户长期记忆”；MES 数据库是实时事实的唯一权威来源。

## 2. 工具治理

Agent 工具目录只记录已经存在或明确规划的能力及其风险边界。目录本身不授予权限，也不会绕过 JWT、用户确认、Spring Boot 服务校验或事务。

当前可用的能力包括：角色范围内的 RAG 检索、工单/追溯/质量实时数据读取、本地 Qwen 局部分析、外部模型总结、以及已经受控的智能排产图和质量报告导出。排产图的写入能力仍只能从既有的确认订单入口进入。

以下能力目前只能标记为规划或保留：现场缺陷图片分析、任意脚本执行、通用外网搜索。模型不得向用户声称它们已经可用。

## 3. 可解释复盘，不暴露思维链

每次已完成的 LangGraph 图运行可基于用户归属的 `agent_graph_checkpoint` 生成一条复盘记录。复盘仅输出：

- 图版本、节点完成/关注情况；
- 订单号、齐套风险、排产后状态、领料后状态等已持久化事实；
- 下一步应回到哪个 MES 页面或业务提示处理。

复盘不输出模型内部思维链，不重新执行图，不恢复图，不写入订单、工单、库存、任务或领料单。

## 4. 人在回路与后续演进

项目已保留订单确认这一人工边界，并有独立的 `SchedulingOrchestrationSidecar` 审批暂停/恢复合同。当前生产排产入口不通过 Sidecar 恢复，以确保既有页面和业务逻辑完全不变。

后续若需要升级为图内审批，应将“暂停—显示审批卡—用户确认—按原线程恢复”作为单独兼容性项目，并验证正常、缺料、阻断领料和取消路径，不能直接替换现有确认动作。
