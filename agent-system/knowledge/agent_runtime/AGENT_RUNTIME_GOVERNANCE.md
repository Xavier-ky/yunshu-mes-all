# 云枢小智 Agent 运行与 RAG 治理规则

> 版本：1.0（2026-07-16）  
> 适用范围：云枢小智主对话、智能排产、质量分析、质量报告，以及后续接入的业务 Agent。  
> 权威依据：当前 FastAPI Agent 服务、Spring Boot 业务接口、`fan_mes` 真实业务数据链路。

## 1. Agent 回答的三类依据

云枢小智不能把三类信息混为一谈。回答、卡片和报告必须清楚区分以下来源：

| 信息类别 | 正确来源 | 可以回答什么 | 不可以代替什么 |
|---|---|---|---|
| 稳定业务规则 | Qdrant RAG 中已审核的 SOP、生命周期、数据边界 | 流程说明、角色职责、状态门禁、下一步操作 | 当前订单、库存、待检数量、任务进度 |
| 实时业务事实 | Spring Boot 的 JWT 转发只读门面，最终来源为 `fan_mes` | 某工单、库存批次、派工、质量趋势、设备待办 | 制度解释与跨业务规则 |
| 受控模型分析 | 本地 Qwen 或外部模型；输入必须是压缩后的规则与事实包 | 风险解释、行动建议、自然语言总结 | 写业务数据、虚构事实、绕过门禁 |

**优先级：** 涉及“现在、今天、这张工单、库存多少、是否可执行”的问题，必须先取实时事实；RAG 只补充解释。事实与 RAG 冲突时，以实时接口和领域服务校验结果为准。

## 2. RAG 的准入与禁入边界

### 可以发布为 approved 知识

- 已落地的 Agent 工作流责任边界、触发语义、真实读写接口、状态门禁和失败处理原则。
- 已上线的质量分析、报告和导出流程的“如何工作”说明。
- 真实业务 Agent 使用的只读数据资源、权限/确认要求与未来能力边界。
- 已有 MES SOP、数据库主线、角色权限和生命周期规则。

### 不得写入共享知识库

- 实时订单、工单、库存、批次、质量指标、安灯、设备待办、报表快照。
- `agent_session`、`agent_message`、用户输入、JWT、密码、连接字符串、模型密钥。
- 演示数据、种子 SQL 原文、前端微文案、模型回复、未审核的设计计划。
- 任何只在内存中存在的 `SchedulingAgentState`、`BusinessAgentState` 或报告临时对象。

动态事实应留在交易数据库、审计库或用户隔离会话中；它们不能因“方便检索”而进入向量库。

## 3. 权限、引用与写入约束

1. 检索固定过滤 `review_status=approved`，并与当前 JWT 角色的 `role_scope` 取交集。
2. RAG 返回必须保留 `document_id`、`source_path`、章节锚点和版本，供 Agent 生成可追溯说明。
3. Agent 运行时所有实时读取均携带当前用户 JWT 与 `trace_id`；失败时应停止或明确降级，禁止以演示值补齐。
4. Agent 包装层不得直连 MySQL 写业务表。业务写入必须复用 Spring Boot 领域服务、权限校验、数量/状态校验和既有事务。
5. 本地或外部模型只能生成解释，不拥有业务提交权。任何新写动作均需具有明确的接口白名单、角色限制与人工确认节点。

## 4. 面向 Agent 的检索决策顺序

```text
识别用户意图
  → 判断问题是否含实时对象/时间词
  → 需要实时事实：先调用受控 MES 只读或领域服务
  → 同时检索角色范围内 approved RAG 规则
  → 以“事实 + 规则引用”构造模型输入
  → 输出结论、风险和下一步；不确定时说明缺失事实
```

示例：

- “工单为什么不能领料？”：先取工单状态、齐套与库存快照，再引用领料生命周期规则。
- “今天质量怎么样？”：先取质量概览/报告快照，再引用质量门禁与处置规则。
- “排产后为什么没有派工？”：先取任务和派工实时快照，再引用排产到派工同步规则。

## 5. 文档更新与回归要求

- 工作流、接口、表主线或状态门禁变化时，先更新对应 Markdown 知识卡，再重新嵌入该 `document_id`。
- 新知识必须写明来源、适用角色、是否含写入、实时数据边界及版本日期。
- 发布前至少验证：指定角色能检索；无关角色不能检索；命中片段可回链；涉及动态问题的回答会调用实时工具。
- Qdrant 是检索副本，不是业务事实库；集合重建后以来源 Markdown 的哈希和检索评测复核。

## 6. 当前成熟度说明

智能排产和质量工作流已具备真实数据读取、部分受控写入或报告导出能力；其它业务 Agent 多数仍是独立、只读包装。界面中“已接入”的展示不能自动推导为“已具备自动写入权限”，应以各 Agent 的真实接口契约为准。
